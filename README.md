# Lost---found-system
Campus Lost &amp; Found System A web-based lost and found management system designed for campus environments, allowing students to report lost items, log found items, and claim belongings.
Features Student Portal: Report lost items, view found items, submit claims, and track claim status

Admin Dashboard: Manage users, verify claims, update item statuses, and oversee all listings

File Uploads: Support for image uploads (JPG, PNG, GIF) up to 5MB

Secure Authentication: Role-based access (Student/Admin) with password hashing

Tech Stack: PHP (Core) MySQL HTML/CSS
